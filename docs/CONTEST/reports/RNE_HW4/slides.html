01

YOLO 簡介

You Only Look Once — 即時物體偵測與影像分割模型

👁️

YOLO 核心特點

01

⚡ 模型特色

  • 2015 年由 Redmon 等人提出
  • 單次前向傳播即可完成偵測
  • 支援目標檢測、語意分割、分類
  • 從 YOLOv1 發展至 YOLOv12、YOLO26

📊 版本演進

v1 (2015)
開創性即時偵測
v3 (2018)
多尺度特徵融合
v5 (2020)
Ultralytics 重寫
v8 (2023)
統一框架支援分割
v12 (2025)
注意力機制增強
YOLO26
最新一代架構
官方文檔：https://docs.ultralytics.com/

02

  • 類別：目標 ID（0=bear, 1=knob）
  • X, Y：邊界框中心座標（歸一化數值 0~1）
  • 寬度, 高度：邊界框尺寸（歸一化數值 0~1）

任務目標

語意分割特點

03

🎨 輸出形式

  • 每像素類別機率圖
  • 不同類別以顏色區分
  • 輸出遮罩（mask）格式

⚙️ 自動處理

  • 訓練時自動影像縮放
  • 線上資料增強
  • 多尺度預測融合

模型選擇與訓練

06

🎯 目標檢測模型

  • yolo26n.pt（nano，最快的模型）
  • yolo26s.pt（small）
  • yolo26m.pt（medium）
  • yolo26l.pt（large）
  • yolo26x.pt（xlarge，最精確）

🗺️ 語意分割模型

  • yolo26n-seg.pt
  • yolo26s-seg.pt
  • yolo26m-seg.pt
  • yolo26l-seg.pt
  • yolo26x-seg.pt
預設 batch size 為 16，若記憶體不足請調小。最佳權重儲存於：detection\runs\detect\train\weights\best.pt
