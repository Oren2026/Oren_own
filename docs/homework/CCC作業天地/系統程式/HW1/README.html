while 迴圈設計原理

核心概念：一次掃描，雙向跳轉

while 迴圈的本質是有條件的重複。在四元組（Quadruple）層次，需要兩個跳轉指令：

指令行為
JMP_F 條件, -, ?若條件為 0（false），跳到 ?（迴圈結束位置）
JMP -, -, 起始位置無條件跳回條件判斷的起點

與 if 的關鍵差異

if 只需要一個 JMP_F（條件為 false 時跳過區塊）。while 需要兩個：JMP_F 離開迴圈 + JMP 回頭。

⭐ 關鍵：loop_start 必須設在 expression() 之前

否則 JMP 會跳到上一輪已經計算過的 JMP_F，而用來判斷的 t4（CMP_LT 結果）不會更新——導致無窮迴圈。

產生的四元組

000: IMM    1          -    t1      ; i = 1
001: STORE  t1         -    i
002: IMM    0          -    t2      ; sum = 0
003: STORE  t2         -    sum
004: IMM    11         -    t3      ; 條件：i < 11  （★ loop_start = 4）
005: CMP_LT i          t3    t4      ; 比較結果放 t4
006: JMP_F  t4         -    ?        ; 為0跳出（回填→013）
007: ADD    sum        i     t5      ; sum = sum + i
008: STORE  t5         -    sum
009: IMM    1          -    t6      ; i = i + 1
010: ADD    i          t6    t7
011: STORE  t7         -    i
012: JMP    -          -    4        ; 回頭到條件起點（★）

p0 函數呼叫機制

編譯階段：四元組生成

指令意義
PARAM a, -, -將參數值放入參數堆疊
CALL f, n, t呼叫函數 f，參數 n 個，結果存入 t
RET_VAL r, -, -回傳值 r

執行階段：呼叫堆疊（Call Stack）

VM 內部用 Frame 模擬每一層函數呼叫：

Frame {
    vars: {}           ; 區域變數
    ret_pc: int        ; 返回地址（CALL 的下一行）
    ret_var: str       ; 回傳值要寫入的目標變數
    incoming_args: []  ; 接收到的參數
    formal_idx: int    ; 參數索引
}

呼叫流程

  1. PARAM：將參數放入 param_stack（因為參數可能是複雜表達式，需先算完）
  2. CALL：建立新 Frame（sp++）、儲存返回地址、搬移參數、跳轉到函數進入點
  3. FORMAL：從 incoming_args 取出值，建立區域變數
  4. RET_VAL：取出回傳值、銷毀 Frame（sp--）、返回到 ret_pc

為什麼支援遞迴？

每次呼叫 sp++ 就開一個新 Frame，遞迴的每一層都有獨立的作用域和變數，不會互相干擾。

python3 compiler.py while.p0
