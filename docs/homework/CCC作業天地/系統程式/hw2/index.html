CalcLang

從直譯器到編譯器的教學語言

一個用於學習編譯器原理的簡單語言。從文字替換開始，逐步建立Tokenizer、AST、Bytecode VM，最終完成一個可用於實際計算的編譯型語言。

語言類型
強型態靜態
目標平台
Stack VM Bytecode
記憶體管理
無 GC（手動）
實現語言
C
學習路徑

解譯器 path（interpreter/）

直接執行：Tokenizer → AST → Eval

L1 電腦基礎：Hello World 完成
L2 直譯器基礎：數字加減 完成
L3 Tokenizer：拆解 Token 完成
L4 AST：語法樹建構 完成
L5 完整計算器（直接執行） 完成

編譯器 path（compiler/）

編譯後執行：Tokenizer → AST → Bytecode → VM

L1 編譯器概念：從解釋器到編譯器 完成
L2 基本運算：1 + 2 * 3 = 7 完成
L3 變數支援：x, y, x+y 完成
L4 while 迴圈：遞迴與跳轉 完成
L5 函數與 Bytecode VM 可執行
Bytecode 指令集
IMM n       載入立即值 n 到堆疊
LOAD idx    從變數陣列取第 idx 個變數 push 到堆疊
STORE idx   pop 堆疊頂存入變數陣列第 idx 格
ADD/SUB/MUL/DIV  pop 兩個值，運算後 push 結果
CMP_LT/GT/EQ     比較，push 1 (真) 或 0 (假)
JMP addr    無條件跳躍到 addr
JMP_FALSE addr   若堆疊頂為 0，跳至 addr
CALL addr   函數呼叫（Level 5）
RET         函數返回（Level 5）
PRINT       pop 並輸出（Level 5）
EOF         程式結束
範例程式

基本運算（Level 2）

1 + 2 * 3;
→ 輸出: 7

變數（Level 3）

x = 5; y = 3; x + y;
→ 輸出: 8

while 迴圈（Level 4）

x = 0; while (x < 3) { x = x + 1; } print(x);
→ 輸出: x = 3
