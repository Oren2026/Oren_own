# Level 1: 從 1+1=2 開始 - 什麼是計算機

## 核心問題：電腦如何做數學？

```
人類用: 1 + 2 = 3 (數學是人類的語言)
電腦用: 0011 + 0010 = 0101 (二進位是電腦的語言)
```

## 實作：最簡單的計算機

目標：用 C 寫一個程式，能計算 `1 + 2` 並輸出 `3`

```c
#include <stdio.h>

int main() {
    int a = 1;
    int b = 2;
    int result = a + b;
    printf("%d\n", result);  // 輸出: 3
    return 0;
}
```

**問題：這算是「程式語言」嗎？**
→ 這是我們寫給人類閱讀的，最後會被 gcc 翻譯成真正的 0/1

## 真正的問題：誰來翻譯？

```
程式設計師寫的文字代碼
        ↓
    gcc 編譯器
        ↓
    10110001... (機器碼)
        ↓
    CPU 執行
```
