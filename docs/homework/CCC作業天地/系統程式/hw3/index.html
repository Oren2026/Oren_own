HW3 在 HW2 的基礎上，新增程序控制、檔案 I/O、時間與睡眠、亂數、字串操作等功能，讓 Solang 不只是計算，而是可以做任何事。

HW3 新功能總覽

程序控制（Process Control）

FORK：fork() 程序複製，建立子程序 / EXIT：結束程式並返回 exit code / EXEC：執行外部命令

標準輸出入（I/O）

PRINT / PRINTLN：輸出字串（不換行/換行）/ READ：讀取一行 stdin

檔案 I/O（File Operations）

FOPEN / FREAD / FWRITE / FCLOSE：開啟、讀取、寫入、關閉檔案

時間與亂數（Time & Random）

TIME：取得目前時間戳 / SLEEP：暫停執行 / RAND：產生亂數

字串操作（String Operations）

STRLEN：回傳字串長度 / STRCMP：比較兩字串 / INT_TO_STR：整數轉字串

13 FORK — 程序複製

介紹

FORK 是 Unix/Linux 系統中最重要的系統呼叫之一，用於複製當前程序（父程序），產生一個幾乎完全相同的副本（子程序）。兩者從同一個記憶體狀態繼續執行，但各自有獨立的 PID。

系統層面發生了什麼
父程序調用 fork()
        ↓
作業系統複製父程序的完整狀態：
  - 記憶體內容（程式碼、全域變數、堆疊）
  - 暫存器狀態
  - 檔案描述符（繼承）
        ↓
+-------------------+-------------------+
|      父程序        |      子程序        |
| fork() 回傳       | fork() 回傳       |
| 子程序的 PID (>0) | 0                 |
+-------------------+-------------------+
VM 語意
FORK 將結果 push 到 stack：
  • 在父程序：push <子程序 PID>（正整數）
  • 在子程序：push 0
使用範例
; 測量子程序是否為子程序
FORK        ; push 0 (子) 或 12345 (父)
DUP         ; 複製 stack 頂端
JZ child    ; 如果是 0（子程序），跳到 child 標籤

; 父程序邏輯
PRINT("Parent: child PID=")
PRINTLN()  ; 印出子 PID

; 子程序邏輯
label child
PRINTLN("I am child")
EXIT(0)

; 等待子程序結束
WAIT         ; 等待子程序並取得 exit code
14 EXIT code exit(code)，結束程式並返回 exit code push 0 → exit → 正常結束
15 EXEC str_idx 執行外部命令（system()），結果壓入堆疊 EXEC("echo hello") → push 0
16 PRINT str_idx 輸出字串（不換行） PRINT("Hello ") → Hello
17 PRINTLN str_idx 輸出字串（換行） PRINTLN("World") → World[newline]
18 READ — 讀取一行 stdin，回傳字串索引 READ → push 0（字串池索引）
19 FOPEN fn_idx + mode_idx fopen(filename, mode)，回傳檔案指標（-1 表示失敗） FOPEN("test.txt", "r") → push 0x1000
20 FREAD fp fgets 讀一行，回傳字串索引（-1 表示失敗） FREAD(fp) → push 1（讀到內容）
21 FWRITE fp, str_idx 寫入字串到檔案，回傳 0（成功）或 -1（失敗） FWRITE(fp, str) → push 0
22 FCLOSE fp fclose，回傳 0（成功）或 -1（失敗） FCLOSE(fp) → push 0
23 TIME — time(NULL)，回傳目前時間戳（int） TIME → push 1779981484
24 SLEEP sec sleep(sec)，暫停指定秒數 SLEEP(1) → 暫停 1 秒
25 RAND max rand() % max，回傳 0 到 max-1 的亂數（max=0 時預設 100） RAND(6) → push 3（擲骰子）
26 STRLEN str_idx 回傳字串長度 STRLEN("hello") → push 5
27 STRCMP idx1, idx2 比較兩字串，回傳 0（相等）、正數或負數 STRCMP("a","b") → push -1
28 INT_TO_STR val 整數轉字串，結果存入字串池，回傳索引 INT_TO_STR(42) → push 2（"42"）

VM 架構說明

HW3 的 VM 基於 HW2 的 Stack VM 改造而來，加入了以下新元件：

String Pool（字串池）

所有字串（包括 PRINT/EXEC 的內容、FOPEN 的檔案名稱與模式）都存在 String Pool 裡，以索引值存取。這樣可以讓 Bytecode 只帶數字索引，不需要攜帶完整字串。

FOPEN 參數封裝

FOPEN 需要兩個字串參數（filename 和 mode）。HW3 用一個 16-bit 整數打包：filename_idx 放高 8 bits，mode_idx 放低 8 bits。解讀時用 (arg >> 8) & 0xFF 取 filename，(arg & 0xFF) 取 mode。

FORK 的父子程序模型

fork() 以後，父子程序各自從同一個 VM 狀態繼續執行。區分方式是：fork() 回傳值在子程序是 0，在父程序是子程序的 PID。
