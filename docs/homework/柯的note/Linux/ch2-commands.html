📂 1｜檔案與目錄操作

指令說明範例備註
ls列出目錄內容ls -la /home-a 顯示隱藏檔，-l 詳細格式，-h 人類可讀大小（第3/4章）
cd切換目錄cd ~, cd -, cd ..~ 家目錄，- 上一個目錄，.. 上一層（第3章）
pwd顯示目前所在路徑pwdPrint Working Directory（第3章）
mkdir建立目錄mkdir dir1, mkdir -p a/b/c-p 同時建立多層子目錄（第3章）
rmdir刪除空目錄rmdir emptydir目錄需為空，否則用 rm -r（第3章）
rm刪除檔案或目錄rm file.txt, rm -rf mydir-r 遞迴刪除，-f 強制刪除，危險操作請三思（第3章）
cp複製檔案或目錄cp src.txt /backup/, cp -r dir/ /backup/-r 複製目錄，-i 覆寫前確認（第3章）
mv移動或重新命名mv old.txt new.txt, mv file.txt /dir/等同於 Windows 的「剪下+貼上」（第3章）
cat顯示檔案完整內容cat readme.txt, cat -n file.txt-n 顯示行號，適合小檔案；大檔案請用 less（第3章）
touch建立空檔案 / 更新時間戳touch new.txt若檔案已存在則更新 mtime（第4章 inode）
ln建立連結（捷徑）ln file hardlink, ln -s /path softlink硬連結 vs 符號連結，差異在 inode（第4章）

📄 2｜內容檢視

指令說明範例備註
head顯示檔案前幾行head -n 20 file.txt預設前 10 行，-n 指定行數（第3章）
tail顯示檔案後幾行tail -n 50 file.txt, tail -f /var/log/syslog-f 動態追蹤（即時看日誌），Ctrl+C 停止（第3章）
more分頁檢視（只能往下）ls -la / | more空白鍵換頁，Enter 換一行，q 離開（第4章）
less分頁檢視（可上下滾）less readme.txt比 more 強，支援 /搜尋、上下鍵滾動，q 離開（第4章）

🔍 3｜檔案搜尋

指令說明範例備註
find進階搜尋（磁碟即時）find /home -name "*.log", find . -size +100M最強大但最慢，可搭配 -exec 對結果動作（第4章）
locate資料庫快速搜尋locate passwd, locate -i readme需先 updatedb，-i 忽略大小寫（第4章）
which確認指令所在路徑which python, which -a python根據 $PATH 查找，-a 列出所有版本（第4章）
whereis搜尋二進位/原始碼/手冊whereis ls比 which 多找原始碼與手冊頁位置（第4章）
type判斷指令類型type cd, type ls內建指令 vs 外部程式，協助理解 Shell 行為（第3章）

📖 4｜說明文件

指令說明範例備註
man指令手冊（分頁說明）man ls, man 5 passwd最完整說明，空白鍵翻頁，q 離開；man 5 指第 5 章節（第3章）
--help快速說明提示ls --help, mkdir --help部分指令支援，直接顯示摘要，不用 man 翻頁
infoGNU 超文字手冊info ls比 man 更完整，支援超連結導航， Emacs 風格操作

💻 5｜系統資訊

指令說明範例備註
whoami顯示目前使用者名稱whoami確認自己是誰，遠端登入後常使用
hostname顯示或設定主機名稱hostname, sudo hostname newname檢視當前主機名稱；設定需 root（第7章）
uname顯示系統資訊uname -a, uname -r-a 全部資訊，-r 核心版本，-m 硬體架構
date顯示或設定系統時間date, date -s "2026-06-03 12:00:00"設定需 root；+%Y%m%d 等格式輸出
cal顯示日曆cal, cal 2026, cal -m 6預設當月；指定月份或年份
who顯示目前登入的使用者who查看誰登入這台機器
w顯示登入者詳細資訊w比 who 更詳細，含正在執行的程序與負載
uptime系統運行時間與負載uptime可快速看機器開機多久

👤 6｜使用者切換

指令說明範例備註
su切換使用者（Substitute User）su - root, su - user2不指定使用者預設切到 root；- 同時載入目標家目錄與環境（第7章）
sudo以 root 權限執行單一指令sudo apt update, sudo -u user2 command需先設定 /etc/sudoers；不需知道 root 密碼（第7章）

su vs sudo 差異：su 會切入另一個使用者環境並持續有效；sudo 只在單一指令前取得臨時權限，執行完畢即恢復普通使用者身份。

⚙️ 7｜程序管理

指令說明範例備註
ps顯示程序快照ps aux, ps -efaux 顯示所有程序（BSD 格式），-ef 顯示完整格式（SysV）（第10章）
kill終止或傳訊號給程序kill 1234, kill -9 1234-9 強制結束，-15 正常終止（預設），先試 -15（第10章）
killall依名稱終止所有程序killall firefox一次砍掉所有同名程序
top互動式程序檢視top動態顯示 CPU、記憶體、程序排名；q 離開；按 M 以記憶體排序（第10章）
pkill依名稱傳送訊號給程序pkill -9 firefox比 killall 更彈性，支援正規表達式

💾 8｜磁碟空間

指令說明範例備註
df顯示檔案系統掛載與空間df -h, df -h /home-h 人類可讀大小；看整體掛載狀況（第4章）
du查詢目錄/檔案磁碟用量du -sh *, du -h --max-depth=1-sh 總計大小；-h 個別子目錄；--max-depth 限制深度（第4章）

✏️ 9｜文字處理

指令說明範例備註
wc計算行數/字數/位元組wc -l file.txt, cat file.txt | wc-l 只算行數，常搭配管線統計前面指令輸出（第3章）
sort排序文字行sort file.txt, sort -rn numbers.txt-r 反向，-n 數字排序，-k 指定欄位（第3章）
uniq過濾相鄰重複行uniq file.txt, sort file.txt | uniq需先 sort 才能正確偵測重複；-c 計算重複次數（第3章）
cut擷取文字欄位cut -d: -f1 /etc/passwd-d 指定分隔符，-f 選擇欄位，擅長處理 CSV/帳號檔
tr字元替換或刪除cat file.txt | tr a-z A-Z大小寫轉換、刪除特定字元，不支援檔案直接讀取（需管線）
grep搜尋並顯示符合列grep "error" log.txt, ls | grep txt功能強大，支援正規表達式，重要章節（第3章）

🛠️ 10｜其他工具

指令說明範例備註
alias設定指令別名alias ll='ls -la'只對當前 session 有效；寫入 ~/.bashrc 永久生效（第3章）
unalias取消別名unalias ll移除已定義的別名
time計時指令執行時間time sleep 3, time ls -la /顯示 real/user/sys 三種時間，效能分析用（第3章）
xargs將上一個指令輸出轉為指令參數find . -name "*.log" | xargs rm -f強大搭配工具，把管線結果轉成參數餵給下一個指令（第3章）
watch定期執行並顯示輸出watch -n 2 date-n 指定間隔秒數，適合監控系統狀態
history顯示指令歷程history, history -c清單顯示並附帶編號；-c 清除歷程；!n 執行第 n 筆（第3章）
echo輸出文字或變數值echo "Hello", echo $PATH印出文字；印出環境變數需加 $（第3章）
export設定或顯示環境變數export VAR=value, export -n VAR設定進程層級變數；-n 取消匯出（第3章）
